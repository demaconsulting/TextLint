title: TextLint
summary: Built-in help of textlint, the cspell-compatible spell checker for code and documentation.
---
{{tool}} checks the spelling of source code and documentation with embedded English and technical-term
dictionaries, configured by a `.textlint.yaml` file, and checks the files in parallel.

Every operation is an option. The only command is `{{tool}} help`, which must be the first argument and takes
topic names, such as `{{tool}} help configuration`.
