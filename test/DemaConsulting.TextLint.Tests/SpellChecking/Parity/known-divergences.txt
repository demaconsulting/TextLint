# Known divergences between TextLint and cspell on the parity corpora.
#
# cspell:disable
#
# The parity test checks that, for every corpus, TextLint's findings equal cspell's recorded findings (expected/NAME.cspell)
# EXCEPT for exactly the findings listed here. A fixed divergence, a new divergence, or a changed position therefore fails
# the test, so every difference from cspell is deliberate and documented (see "Differences from cspell" in the user guide).
#
# One line per finding: CORPUS | SIDE | LINE:COLUMN WORD [kind] | REASON
#   SIDE "+" : TextLint reports the finding and cspell does not.
#   SIDE "-" : cspell reports the finding and TextLint does not.
#   kind    : "flagged" for a flagged word, "directive" for an unsupported directive, "invalid" for an ignoreRegExp directive
#             whose pattern cannot be used; omitted for an unknown word.
# Blank lines and lines that start with "#" are ignored.

# --- cspell's heuristic splitter: after the case split, cspell re-splits an unknown word with a dictionary-driven search
# --- and keeps the result when it finds fewer problems. TextLint deliberately has no such search.
divergences | + | 1:1 QUIXs | An acronym with a plural ending that is unknown: cspell's search accepts it, TextLint reports it
divergences | + | 1:7 QUIXes | The same for a different ending
divergences | - | 2:5 QUIXF | cspell's search glues the last capital to the neighboring word; TextLint splits at the case change
divergences | + | 2:5 QUIX | The first piece of the case split that cspell does not report
divergences | + | 2:9 Flib | The second piece of the case split that cspell does not report
divergences | - | 3:1 quix中文zorb | cspell reports the whole run when Han characters sit between two Latin words
divergences | + | 3:1 quix | TextLint never treats Han characters as part of a word, so it reports each Latin word
divergences | + | 3:7 zorb | The second Latin word of the same run
divergences | + | 5:9 zorv | A listed word with punctuation followed by more punctuated text: cspell's search finds the listed prefix
divergences | + | 5:19 zorv | The same with letters after the listed word; TextLint matches a list entry only against a whole token
divergences | + | 6:9 nzorbq | cspell remembers that nzorbq was accepted through the escape rule (\nzorbq) and accepts it later in the same file; TextLint accepts it only directly after a backslash

# --- Dictionaries differ: TextLint embeds its own word lists, cspell its own.
divergences | - | 4:2 nbsp | The word nbsp is in TextLint's HTML word list and not in cspell's dictionaries

unsupported-directives | + | 2:11 dictionary directive | The dictionary directive is reported, not applied

# --- The ignoreRegExp directive is applied like cspell applies it. cspell silently drops a pattern it cannot use, so a
# --- hidden word that depends on it is shown in both; TextLint also reports the directive, and reads a name that nothing
# --- defines as an error instead of a literal expression.
ignore-regexp | + | 35:24 /(?i)zorbinline/ invalid | TextLint reports a pattern with an inline option, which it cannot translate; cspell drops it silently
ignore-regexp | + | 37:24 ZorbMissing invalid | TextLint reports a name that nothing defines; cspell reads it as the literal expression
ignore-regexp | + | 38:1 zorbmissing | cspell hides the word with the literal expression; TextLint reports it, because the name is not a pattern
ignore-regexp | + | 41:24 /zorbbad[/ invalid | TextLint reports a pattern that is not a valid expression; cspell drops it silently
ignore-regexp | + | 43:11 ignoreRegExp directive | A directive with no pattern is reported; cspell ignores it
